# 倒计时计时器 (Countdown Timer)

一个美观、功能完整的倒计时计时器应用，支持实时显示每秒倒计时，具有数字翻转动画效果和完善的交互反馈。

## 功能特性

- **实时倒计时**: 每秒更新显示，精确计时
- **翻转动画**: 数字变化时卡片从中间翻转的3D效果
- **悬停状态**: 所有交互元素都有悬停反馈效果
- **Toast 通知**: 操作反馈通过 Toast 弹窗展示
- **预设时间**: 快速设置常用时间（1分钟、5分钟、10分钟、30分钟）
- **声音提醒**: 倒计时结束时播放提示音
- **响应式设计**: 适配不同屏幕尺寸

## 项目结构

```
countdown-timer/
├── index.html      # 主页面结构
├── style.css       # 样式文件（包含翻转动画、悬停效果）
├── script.js       # JavaScript 逻辑（倒计时、Toast反馈）
├── README.md       # 项目说明文档
└── .gitignore      # Git 忽略文件配置
```

## 文件说明

### index.html
- 页面主体结构
- 引入 Ant Design CSS 重置样式
- 引入 Day.js 时间处理库
- 包含输入区域、倒计时显示区域、控制按钮、预设按钮

### style.css
- 渐变背景设计
- 卡片翻转动画（CSS 3D Transform）
- 按钮悬停效果
- Toast 弹窗动画
- 响应式布局适配

### script.js
- `CountdownTimer` 类：核心倒计时逻辑
- 开始/暂停/重置功能
- 数字翻转动画控制
- Toast 消息提示系统
- Web Audio API 提示音

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 输入小时、分钟、秒数，或点击预设按钮快速设置
3. 点击「开始」按钮启动倒计时
4. 可随时点击「暂停」或「重置」按钮

## 技术栈

- **HTML5**: 页面结构
- **CSS3**: 样式、动画、响应式设计
- **JavaScript (ES6+)**: 交互逻辑
- **Ant Design CSS**: 基础样式重置（CDN）
- **Day.js**: 时间处理（CDN）
