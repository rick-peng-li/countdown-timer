# 启动倒计时计时器

一个功能完整的启动倒计时计时器，支持实时每秒倒计时显示，数字变化时带有卡片翻转动画效果。

## 功能特性

- ✨ 实时每秒倒计时显示
- 🎴 数字变化时卡片从中间翻转效果
- 🖱️ 所有交互元素支持悬停状态
- ⏯️ 开始/暂停/重置功能
- 💬 使用 Ant Design 组件库实现 Toast 反馈
- 📱 响应式设计，支持移动端
- ⏱️ 支持自定义倒计时时间（1-3600秒）

## 技术栈

- HTML5
- CSS3 (含 CSS3 动画)
- JavaScript (ES6+)
- Ant Design (CDN 引入)

## 使用方法

1. 直接在浏览器中打开 `index.html` 文件
2. 输入倒计时时间（秒），范围 1-3600 秒
3. 点击"开始倒计时"按钮启动倒计时
4. 可随时暂停或重置倒计时
