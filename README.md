# ⏰ 倒计时计时器

一个美观、功能完整的网页倒计时计时器，支持实时每秒倒计时、数字翻牌动画效果和 Toast 提示反馈。

## ✨ 功能特性

- **实时倒计时**：精确到秒的倒计时显示
- **翻牌动画**：数字变化时卡片从中间翻转的视觉效果
- **时间设置**：支持小时、分钟、秒的手动输入
- **快速设置**：提供 1分钟、5分钟、10分钟、25分钟、1小时 等快捷按钮
- **进度条**：实时显示倒计时进度百分比
- **控制按钮**：
  - 开始/继续：启动或恢复倒计时
  - 暂停：暂停当前倒计时
  - 重置：重置计时器到初始状态
- **Toast 提示**：操作反馈通过美观的 Toast 消息展示
- **完成提醒**：倒计时结束时播放提示音并显示动画效果
- **响应式设计**：适配桌面和移动设备

## 📝 使用说明

### 设置时间
1. 在输入框中输入小时、分钟、秒
2. 或点击快速设置按钮一键设置

### 控制计时器
- 点击**开始**按钮启动倒计时
- 点击**暂停**按钮暂停倒计时
- 点击**继续**按钮恢复倒计时
- 点击**重置**按钮重置计时器

### 翻牌效果
当数字变化时（每秒），对应的数字卡片会执行从中间翻转的动画效果，增强视觉体验。
